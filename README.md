## 🔵 Launch

Run the launcher from the repository root:

```bash
chmod +x ./start.sh
./start.sh
```

## 🔴 Notes

- Keep `start.sh` in the repository root.
- Run the script from the repository directory.
- If the script is not executable, use the `chmod` command above first.
